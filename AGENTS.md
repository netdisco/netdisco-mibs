
# How to make an agentic PR for a new or update mib

 * determine the MIB file or archive that is required
 * make sure to not negatively affect the users host machine with the instructions that follow, best use a container or microvm since we'll be touching the git and net-snmp installations
 * exactly follow all instrcutions in https://github.com/netdisco/netdisco-mibs/wiki/Updating-MIBs
 * reiterate the essential points that you followed in the commit message
 * on success, create a pull request in https://github.com/netdisco/netdisco-mibs
